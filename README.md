# Little Angels Modern High School Website

A clean, modern, and professional website for Little Angels Modern High School featuring a minimal black and white design with Poppins font.

## Features

- Responsive design that looks great on all devices (mobile, tablet, desktop)
- Clean and professional UI/UX with minimal black and white color scheme
- Interactive elements including image sliders, testimonials, and forms
- WhatsApp and Email contact buttons
- Admissions popup
- Mobile-friendly navigation

## Pages

1. **Home Page (index.html)**
   - Header with navigation
   - Hero image slider
   - CTA section
   - School features
   - Enquiry form
   - Testimonials
   - Vision & Mission
   - Footer with contact info and map

2. **Admission Page (admission.html)**
   - Admission information
   - Application form
   - Step-by-step admission process

3. **Admin Login (admin-login.html)**
   - Secure login interface for school administrators

## Setup Notes

1. Images are not included in this repository. Before deploying, add the following images to the `/images` directory:
   - `school-logo.png` - The school logo
   - `slider1.jpg`, `slider2.jpg`, `slider3.jpg` - Hero slider images
   - `admission-banner.jpg` - Banner image for the admission page

2. The website is built using only HTML, CSS, and JavaScript with no external frameworks or libraries except for:
   - Google Fonts (Poppins)
   - Font Awesome icons

## Design Guidelines

- Primary Color: Black (#000000)
- Secondary Color: White (#ffffff)
- Accent Color: Blue (#3498db)
- Font: Poppins (Light, Regular, Medium, SemiBold, Bold)
